## 为什么

当前 PDF 导出使用均匀切片方式（按 A4 高度等分切割 Canvas），导致内容块在页面边界被截断，出现半截文字、表格被腰切等问题，严重影响报告可读性和专业感。

## 变更内容

将 PDF 分页算法从**均匀切片**改为**DOM 感知分页**：在 Canvas 截图后，先测量所有报告内容块的 DOM 位置，按比例映射到 Canvas 坐标，然后在块与块之间的空白间隙处进行页面分割，确保每个内容块不被截断。超长内容块（单块超过一页）仍可跨页截断（降级为原行为）。

## 功能 (Capabilities)

### 新增功能

无

### 修改功能

- `pdf-export`: PDF 生成算法从均匀切片改为 DOM 感知分页，切分位置由内容块间隙决定，而非固定 A4 高度
- `report-quality`: PDF 报告页面不再出现内容截断，页面分割点始终位于内容块之间

## 非目标

- 不引入新的依赖（如 html2pdf.js、@react-pdf 等）
- 不改变报告的视觉样式（边距、字体、颜色等保持不变）
- 不改变报告模板的内容结构或新增/删除内容块
- 不解决超长内容块跨页截断的问题（此类情况降级为均匀切片行为）

## 影响

- `src/utils/exportReport.js` — 核心切片算法重写
- `src/components/decision/ReportTemplate.vue` — 给部分未覆盖的内容块添加标记 class，用于 DOM 选择器
- `openspec/specs/pdf-export/spec.md` — 更新 PDF 生成规范描述
- 无 API、依赖变更
