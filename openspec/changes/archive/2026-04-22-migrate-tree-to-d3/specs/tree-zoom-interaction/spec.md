# spec: tree-zoom-interaction

## 新增需求

### 需求:缩放拖拽交互

系统必须支持用户通过鼠标对决策树进行缩放和拖拽平移：
- 使用 d3.zoom 实现平滑的缩放和平移
- 支持鼠标滚轮缩放和拖拽平移
- 缩放级别应有限制范围（最小 0.3x，最大 3x）
- 缩放时节点文字保持清晰（SVG 矢量渲染）
- 禁止用户手动拖拽单个节点位置

#### 场景:鼠标滚轮缩放
- **当** 用户在决策树区域滚动鼠标滚轮
- **那么** 决策树以鼠标位置为中心进行缩放

#### 场景:拖拽平移
- **当** 用户在决策树空白区域按住鼠标左键并拖动
- **那么** 整个决策树画布随之平移

#### 场景:缩放边界限制
- **当** 用户缩放到最小或最大边界
- **那么** 缩放操作停止在 0.3x 最小值和 3x 最大值

#### 场景:禁止节点拖拽
- **当** 用户尝试拖拽单个节点
- **那么** 节点位置保持不变，不允许手动重排
