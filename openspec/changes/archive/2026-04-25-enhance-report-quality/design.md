# 设计：提升报告专业质感

## 全局约束：商务冷感

报告采用"商务冷感"视觉基调，以区别于常规 SaaS 仪表盘风格：
- **直角原则**：所有容器、卡片、矩阵单元格统一无圆角（`border-radius: 0`）
- **背景克制**：使用 `#F5F5F5` 灰底替代蓝色系底色
- **文字纯黑**：标题 `#000`，正文 `#333`，辅助信息 `#888`
- **颜色去情绪化**：正向/负向偏移使用灰色而非红绿对比

## 报告架构

报告采用 `ReportTemplate.vue` 独立组件，通过 `h()` + `render()` 离屏渲染到 `#report-target` 容器，再调用 `html2canvas` + `jsPDF` 导出 PDF。

三页强制结构：

```
Page 1: 决策背景与参数快照
├── 推荐结论（定音鼓）
├── 参数配置表
└── 方案能力对比（CSS 条形图）

Page 2: 路径推演
├── 竖向时间轴
├── 安全边际表
└── 风险压测推论

Page 3: 执行摘要与归因
├── 方案排名
├── 归因矩阵
└── 机会成本注脚 + 免责声明
```

## 关键决策

1. **置信度计算**：基于 Top1/Top2 得分差，>10 = 显著占优，>3 = 适度领先，<=3 = 竞争胶着
2. **归因矩阵**：维度 x 选项交叉表，每行最大绝对值标记 `★`（决胜因子）
3. **风险分级**：threshold 缺口 >15 = 稳健，>5 = 紧平衡，<=5 = 脆弱
4. **方案能力图**：使用 CSS 水平条形图（非 canvas），极细灰线网格，深灰→浅灰区分方案
