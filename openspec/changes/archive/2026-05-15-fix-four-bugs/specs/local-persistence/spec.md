## 修改需求

### 需求:清除缓存入口

系统 SHALL 在 UI 中提供"清除本地缓存"按钮。用户点击时必须弹出确认对话框，用户确认后方可执行清除操作，清除完成后展示成功提示消息。

#### 场景:用户清除缓存
- **当** 用户点击"清除缓存"按钮
- **那么** 弹出确认对话框，询问"确定要清除本地缓存吗？此操作不可撤销"
- **当** 用户点击确认
- **那么** 删除 localStorage 中的决策模型数据
- **那么** 展示"缓存已清除"成功提示

#### 场景:用户取消清除
- **当** 用户点击"清除缓存"按钮后点击取消
- **那么** 不执行清除操作，不展示任何提示
