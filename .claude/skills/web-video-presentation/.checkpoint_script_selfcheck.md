## 形式层（8 条原则）

- [x] **信息保留度 ≥ 60%**：原文 ~600 字（产品定义卡片核心内容），script ~820 字，保留度 > 100%（口播稿实际展开更口语化，字数更多但信息量一致）
- [x] 无 emoji / 无书名号 / 无括号补充 / 无"据 XX 报告显示"类引文格式
- [x] 每句 ≤ 20 字（已检查，最长句约 18 字）
- [x] 大量使用"你"（第二人称），如"你做决定的时候"、"你更看重"
- [x] 开头 3 秒钩子："你做决定的时候，能不能看到未来？" — 悬念型
- [x] 数字已翻译："5000 次"保留（核心冲击数字），"正负百分之二十"而非"±20%"
- [x] 无"首先/其次/最后"结构词
- [x] 有具体例子（"300 分高考"、"砍掉产品线"、"风险控制调到 80"）

## 风骨层（去 AI 味五类）

- [x] 无"说白了/本质上/底层逻辑/恰恰/反而/正是因为/归根结底"等 AI 高频词
- [x] 开头第一句是悬念钩子，不是假共情
- [x] 无"我必须认真说/可能会颠覆你的认知"等自我加权
- [x] 无连续 ≥3 句结构相同的排比
- [x] 结尾是具体金句，不是"希望对你有帮助/以上就是本期内容"
