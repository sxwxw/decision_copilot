# 设计：深度模拟

## 数据流

```
┌─────────────────────────────────────────────────────────┐
│  前端: 用户拖动滑块 → state.paramValues = {90,10,80,30}  │
└──────────────────────────┬──────────────────────────────┘
                           │
                           ▼
              点击「深度模拟」按钮
                           │
                           ▼
┌─────────────────────────────────────────────────────────┐
│  POST /api/decision/refine                               │
│  { currentModel: {...}, paramValues: {...} }             │
└──────────────────────────┬──────────────────────────────┘
                           │
                           ▼
┌─────────────────────────────────────────────────────────┐
│  LLM (DECISION_REFINE_PROMPT, 开启思考模式)               │
│  约束：                                                   │
│    1. options 必须与 currentModel.options 一致             │
│    2. variables 维度不变                                   │
│    3. trade_offs.dimension 必须是变量名之一                │
│    4. 返回完整的 model 结构                                │
│    5. recommendation.delta_analysis 包含对比文案           │
└──────────────────────────┬──────────────────────────────┘
                           │
                           ▼
┌─────────────────────────────────────────────────────────┐
│  前端: 收到新 model                                       │
│    - 替换 state.model (含新 treeData/paths/scores)        │
│    - 记录 state.snapshotWeights = {90,10,80,30}           │
│    - 滑块位置不变                                         │
│    - adaptTree + 重新选中根节点                            │
└──────────────────────────┬──────────────────────────────┘
                           │
                           ▼
┌─────────────────────────────────────────────────────────┐
│  后续用户再调滑块 (90→95):                                │
│    recalcScores 基于新树的 trade_offs + snapshotWeights   │
│    shift = (currentValue - snapshotValue) / 100 × delta  │
└─────────────────────────────────────────────────────────┘
```

## 关键决策

1. **选项锚定**：prompt 中明确 options 列表，禁止增删改
2. **维度锁定**：trade_offs.dimension 必须是已有变量名
3. **快照机制**：snapshotWeights 记录深度模拟时的参数位置，后续微调计算增量偏移
4. **delta_analysis**：LLM 在 recommendation 中输出对比文案，前端用 el-alert 展示
5. **按钮视觉**：参数偏离时按钮从 plain → primary + 灰色提示文字
