用户故事
1. 角色：需要在不确定环境中做出关键抉择的管理者、创业者、项目负责人或面临复杂选择的个人。
2. 场景：面临多个互斥选项（如：是否砍掉核心业务线、选择哪种技术架构、是否进入新市场），变量错综复杂且存在不确定性。
3. 问题：传统"拍脑袋"缺乏依据；Excel 决策矩阵建模门槛高且无法处理维度间的逻辑对冲；直接问 LLM 又显得"黑盒"不可信，无法追溯推理过程。
4. 使用：输入决策诉求 → AI 自动构建逻辑沙盘 → 拖动滑块注入主观偏好，分数实时变化 → 点击节点追溯完整推理路径 → 触发仿真与对抗审查进行压力测试 → 导出专业级决策报告。本地自动保存进度，刷新后可恢复。

核心功能
1. AI 决策建模：输入自然语言问题，自动提取选项、识别关键变量与因果链，构建结构化决策树。支持输入校验拦截非决策类问题。
2. 动态实时评估：参数调整后 ~300ms 内重算分数与排名变化，同步输出归因文案（"你重视风险控制，该方案在此项不足"），支持预设风险偏好一键对比。
3. 多路径推演溯源：每个选项展开为多条逻辑路径（乐观/悲观/基准），点击决策树节点查看从根到叶的完整路径链，含概率、核心推动力与风险评估。
4. 蒙特卡洛仿真：内置 7 种概率分布，5000 次随机抽样，输出 P10/P50/P90 分布与标准差，量化不确定性。
5. 敏感性分析：对每个变量 ±20% 扰动，评级排名稳定性（稳定/部分稳定/不稳定），识别会导致结论翻转的关键变量。
6. DEVIL 对抗性审查：攻击排名第一的选项、为排名最后的选项辩护，检测 7 种认知偏置（乐观偏差/幸存者偏差/锚定效应等）。
7. 多 Agent 流水线：FRAMEWORK → MODEL → SIMULATE → NEXUS 4 步独立推演，支持内循环自我校准模型偏差、外循环重塑决策框架，SSE 实时推送进度。
8. 模型修正：根据用户偏好与偏差发现，触发模型重新建模，迭代优化决策结构。
9. 本地持久化：模型变更自动保存至 localStorage，刷新页面恢复上次决策状态，支持一键清除。
10. 结果导出：一键导出深度分析报告（PDF）。

AI 价值点
传统决策矩阵（加权打分表）需要用户自己识别维度、分配权重、估算分值——这本身就需要决策能力。本产品用 LLM 一次性完成建模最难的前置工作：从自然语言中提取选项、识别关键变量、构建因果树、推演路径概率。在此基础上，AI 进一步承担三项人类难以完成的工作：
• 蒙特卡洛仿真：5000 次随机抽样量化不确定性，人工无法在可接受时间内完成
• 对抗性审查：以"魔鬼代理人"角色系统性地攻击结论、检测认知偏置，人类天然存在确认偏误难以做到
• 多 Agent 独立推演：4 步流水线互不干扰，降低单步建模的系统性偏差
用户只需在 AI 生成的模型上"微调偏好"即可获得量化结果。LLM 负责"从无到有"，前端公式负责"实时响应"，量化引擎负责"压力测试"，三者互补。

关键交互
1. 左侧输入决策问题并点击"提交"，AI 在数秒内生成分层决策树和量化模型。
2. 左侧参数面板自动生成滑块和选择器，用户拖动滑块调整偏好（如"风险控制"调高至 80），右侧决策树和底部方案概览实时响应分数偏移、排名变化和归因文案。
3. 建模完成后，点击"深度模拟"触发蒙特卡洛仿真与敏感性分析；切换底部 Tab 查看 DEVIL 对抗审查结果。
4. 点击"多 Agent 流水线"按钮启动 4 步独立推演，SSE 实时推送每步进度，支持从失败步骤恢复。
5. 点击决策树上任意节点，底部切换为路径溯源视图，显示完整推理链路、概率分布与归因分析，可一键导出 PDF 报告。
