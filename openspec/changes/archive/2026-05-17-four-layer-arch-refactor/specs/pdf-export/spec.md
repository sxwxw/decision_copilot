# spec: pdf-export

## 修改需求

### 需求:导出时间戳

系统 SHALL 在导出时计算当前时间，而非在模块加载时固定。

#### 场景:多次导出时间不同
- **当** 页面打开后等待 1 小时再导出
- **那么** 报告中的时间显示为导出时刻，而非页面加载时刻

### 需求:导出渲染等待

系统 SHALL 在截图前等待 ReportTemplate 的 DOM 完全渲染，而非仅 1 个 requestAnimationFrame。

#### 场景:复杂报告完整截图
- **当** 报告包含表格、网格、多个章节
- **那么** html2canvas 捕获到完整 DOM，无空白区域
