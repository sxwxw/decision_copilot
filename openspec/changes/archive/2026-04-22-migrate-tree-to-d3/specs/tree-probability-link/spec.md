# spec: tree-probability-link

## 新增需求

### 需求:概率连线样式

系统必须使用贝塞尔曲线连接决策树节点，连线样式必须反映路径的概率值：
- 线宽（stroke-width）与概率值成正比，高概率路径更粗
- 高风险（negative eventType）路径使用虚线
- 连线末端带有小三角形箭头，指向子节点
- 连线中点（通过 getPointAtLength 精确计算）显示 "P=xx%" 标签

#### 场景:渲染高概率连线
- **当** 连线的目标节点概率 >= 0.5
- **那么** 连线使用较粗的实线（stroke-width >= 3px）

#### 场景:渲染低概率连线
- **当** 连线的目标节点概率 < 0.5
- **那么** 连线使用较细的线（stroke-width <= 2px）

#### 场景:渲染高风险连线
- **当** 连线目标节点的 eventType 为 "negative"
- **那么** 连线使用虚线样式（stroke-dasharray）

#### 场景:显示连线概率标注
- **当** 连线渲染完成
- **那么** 在贝塞尔曲线精确中点处显示 "P=xx%" 小标签

#### 场景:连线末端箭头
- **当** 连线渲染完成
- **那么** 连线末端（靠近子节点处）显示指向子节点的小三角形箭头
