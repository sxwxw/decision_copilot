# spec: decision-tree-visualization

## 修改需求

### 需求:决策树可视化

系统必须使用 D3.js 渲染决策树为 SVG 图形，支持胶囊卡片节点、概率连线、路径追溯和缩放交互。

#### 场景:决策树渲染
- **当** 决策树数据通过 treeData prop 传入
- **那么** 系统使用 D3.js 渲染 SVG 决策树，节点为胶囊卡片，连线为贝塞尔曲线

#### 场景:点击节点触发路径详情
- **当** 用户点击决策树中的任意节点
- **那么** 系统触发 nodeClick 事件并传递该节点的数据

#### 场景:路径追溯高亮
- **当** 用户点击决策树节点
- **那么** 从根到该节点的路径高亮为紫色，非路径节点淡化至 0.2 透明度

#### 场景:缩放拖拽
- **当** 用户在决策树区域操作
- **那么** 用户可通过鼠标滚轮缩放和拖拽平移画布

## 移除需求

### 需求:决策树可视化（ECharts 版）
**Reason**: 已迁移至 D3.js 实现，ECharts tree series 无法满足自定义节点 DOM 和精细交互的需求
**Migration**: 使用 D3.js 版本的 DecisionTree.vue 替换原 ECharts 版本，组件接口（props/emit）保持不变
