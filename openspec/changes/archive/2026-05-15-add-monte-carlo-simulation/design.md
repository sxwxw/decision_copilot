## 上下文

当前评分完全由 LLM 生成 JSON 中的 baseScore + 前端线性公式计算。AI-Decision-Engine 项目有一个 Python 蒙特卡洛仿真器，支持 7 种分布、10000 次抽样、敏感性分析。

## 目标 / 非目标

**目标：**
- 移植仿真器到 TypeScript，作为深度模拟的计算引擎
- 保留现有线性公式作为快速模式（拖滑块实时反馈）
- 修复 counterfactual 为动态生成

**非目标：**
- 不替换现有评分公式（两者共存）
- 不引入 Web Worker（初期主线程运行，后续优化）

## 决策

### 1. 双模式共存

| 模式 | 触发时机 | 计算方式 | 输出 |
|------|---------|---------|------|
| 快速模式 | 拖滑块 | 线性公式 | 即时调整分数 |
| 深度模式 | 点"深度模拟" | 蒙特卡洛 | P10/P50/P90 + 排名 |

### 2. 仿真器输入契约

LLM prompt 升级：为每个变量输出 `sim_spec` 字段，包含 distribution type 和参数：
```json
{ "name": "收入预期", "sim_spec": { "type": "lognormal", "params": { "mean": 60, "sd": 15 } } }
```

### 3. counterfactual 动态化

从 `state.model.variables` 动态生成 optimistic/pessimistic/neutral 场景，而非硬编码变量名。

## 风险 / 权衡

[风险] → 双模式给出不同排名，用户困惑
→ 缓解：快速模式标注"线性近似"，深度模式标注"概率推演"，深度结果优先展示

[风险] → 仿真在主线程运行 >5000 次时阻塞 UI
→ 缓解：初期限制仿真次数 ≤ 5000，后续迁移到 Web Worker

[风险] → LLM 可能输出不合理的分布参数（如正态分布 mean=200 超出 [0,100]）
→ 缓解：仿真器 validate 阶段校验分布参数范围
