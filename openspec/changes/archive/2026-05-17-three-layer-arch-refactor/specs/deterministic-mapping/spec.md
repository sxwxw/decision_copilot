## 新增需求

### 需求:定性标签映射为定量初始值
系统 MUST 提供确定性映射表，将 LLM 输出的定性标签（如"高概率"、"强正向 delta"）转换为量化初始值。

#### 场景:概率标签映射
- **当** 系统收到 `probability_label` 为"极高"、"高"、"中"、"低"、"极低"
- **那么** 分别映射为 0.85、0.70、0.50、0.30、0.15 的概率初始值

#### 场景:delta 标签映射
- **当** 系统收到 `delta_label` 为"强正向"到"强负向"
- **那么** 分别映射为 15、10、5、0、-5、-10、-15 的 delta 初始值

#### 场景:标签缺失时使用 LLM 数值兜底
- **当** LLM 未输出定性标签但输出了数值（过渡期兼容）
- **那么** 系统 MUST 使用该数值，并记录 warning 日志提示"LLM 未输出定性标签"

### 需求:拓扑错误拦截
系统 MUST 在 LLM 输出后、展示前拦截拓扑级数据错误，阻断不合格模型流入前端。

#### 场景:路径概率不归一
- **当** 某选项下所有路径的概率总和偏离 1.0 超过 0.05 容差
- **那么** 系统 MUST 调用 `probNormalizer` 进行归一化修正，并记录 warning

#### 场景:权重和不归一
- **当** 所有权重的总和偏离 1.0 超过 0.05 容差
- **那么** 系统 MUST 将权重按比例缩放至和为 1.0

#### 场景:字段缺失阻断
- **当** 模型缺少必填字段（options、treeData、paths 等）
- **那么** 系统 MUST 返回 error 级别校验结果，拒绝该模型
