## 新增需求

### 需求:仿真结果数据模型

系统 SHALL 在 `state.model` 中为每个选项增加仿真结果字段：`p10`、`p50`、`p90`、`sigma`、`utility_mean`。

#### 场景:仿真结果写入 state
- **当** 蒙特卡洛仿真完成
- **那么** 每个选项的仿真统计结果被写入 `state.model.paths[i].simulationResult`

### 需求:快速模式与深度模式共存

系统 SHALL 保留现有线性加权评分公式（快速模式），同时支持蒙特卡洛仿真（深度模式）。

#### 场景:拖动滑块时
- **当** 用户拖动参数滑块
- **那么** 使用线性公式实时更新评分，不调用仿真器

#### 场景:点击深度模拟时
- **当** 用户点击"深度模拟"按钮
- **那么** 调用蒙特卡洛仿真器，返回 P10/P50/P90 区间，覆盖展示区域的评分
