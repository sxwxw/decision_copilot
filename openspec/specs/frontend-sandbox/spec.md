## 新增需求

### 需求:前端展示影响方向
前端 MUST 在参数交互时展示"影响方向"提示（如 ↑ 正向拉动 / ↓ 负向拖累），而非频繁跳动的黑盒绝对分数。

#### 场景:滑块变化时展示方向箭头
- **当** 用户调整滑块参数
- **那么** 对应方案卡片上 MUST 显示方向箭头和变化量（如 ↑ +5），而非仅显示新分数

#### 场景:分数稳定时隐藏方向标注
- **当** 滑块无变化超过 300ms
- **那么** 方向箭头淡出，仅显示基准分数

## 修改需求

### 需求:置信度展示
NexusReport 组件 MUST 在数据异常时展示明确的失败原因，而非仅显示"低置信度"标签。

#### 场景:数据异常导致低置信度
- **当** V2 管线校验发现 error 且置信度被强制锁死在 40
- **那么** NexusReport 中 MUST 显示"量化基础不通过"的批判文案
