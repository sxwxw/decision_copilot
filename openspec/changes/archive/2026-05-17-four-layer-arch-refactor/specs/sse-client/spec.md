# spec: sse-client

## 新增需求

### 需求:SSE 流管理

系统 SHALL 提供 SSE 客户端 `sseClient`，管理 Server-Sent Events 流的生命周期，支持超时、取消和错误上报。

#### 场景:正常 SSE 流接收
- **当** 发起 SSE 请求并服务端持续发送事件
- **那么** 客户端按事件类型分发到对应的回调函数

#### 场景:SSE 流超时
- **当** 服务端在 60 秒内未发送任何数据
- **那么** 客户端触发 AbortController 终止连接，并调用 onError 回调

#### 场景:用户主动取消
- **当** 用户在 SSE 流进行中调用 cancel()
- **那么** 客户端终止连接，onCancel 回调被触发

#### 场景:解析错误不上报静默
- **当** 服务端发送非 JSON 格式的 data
- **那么** 客户端记录 parse error 并调用 onError，不静默吞掉

#### 场景:连接断开后错误处理
- **当** 客户端 TCP 连接在流进行中关闭
- **那么** 客户端捕获错误并调用 onError，不抛出未捕获异常
