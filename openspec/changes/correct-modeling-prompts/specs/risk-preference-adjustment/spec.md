## 新增需求

### 需求:风险偏好作为显式概率调节因子

决策树每个 Option 节点必须包含 `risk_adjustment` 对象，定义不同风险偏好类型（保守/均衡/激进）下该选项的基准分偏移量和路径概率调节因子。前端和蒙特卡洛仿真引擎必须读取此字段，根据用户当前选择的风险偏好类型动态调整分数和概率。

#### 场景:均衡型用户获得无偏移基准分
- **当** 用户选择"均衡"风险偏好
- **那么** 所有选项的基准分偏移量为 0，路径概率调节因子为 1.0

#### 场景:保守型用户偏好稳定选项
- **当** 用户选择"保守"风险偏好
- **那么** 低风险选项（risk_level=低）的基准分增加，高风险选项（risk_level=高）的基准分减少，且乐观路径概率降低

#### 场景:激进型用户偏好高回报选项
- **当** 用户选择"激进"风险偏好
- **那么** 高风险选项的基准分增加，乐观路径概率升高

#### 场景:风险偏好缺失时使用默认值
- **当** LLM 返回的模型不包含 `risk_adjustment` 字段
- **那么** 系统使用默认值：所有类型 offset=0，probability_factor=1.0

### 需求:蒙特卡洛仿真纳入风险偏好调节

蒙特卡洛仿真引擎在执行 `runMonteCarlo` 时，必须根据用户当前风险偏好类型对每个 Option 的效用值应用 `probability_factor` 调节。调节方式：`adjusted_utility = base_utility + offset`，其中 offset 和 probability_factor 来自该选项的 `risk_adjustment` 中当前风险偏好类型的值。

#### 场景:仿真结果随风险偏好变化
- **当** 用户对同一模型切换风险偏好并重新运行仿真
- **那么** 仿真排名可能发生变化，因为不同风险偏好类型的 offset 和 probability_factor 不同
