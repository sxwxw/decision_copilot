# spec: pdf-export

## 修改需求

### 需求:PDF 生成

- 系统 SHALL 使用 `html2canvas` 以 2x DPI 捕获报告内容
- 系统 SHALL 使用 `jsPDF` 创建 A4 纵向页面
- 系统 SHALL 在切片前测量报告中所有 `.pdf-block` 元素的 DOM 位置，按比例映射到 Canvas 坐标
- 系统 SHALL 将页面截断点设置在 `.pdf-block` 元素之间的空白间隙处，禁止在内容块内部截断
- 系统 SHALL 当单个内容块高度超过 A4 页面高度时，在块内部按 A4 高度截断（降级行为）
- 系统 SHALL 生成文件名 `decision-report-{timestamp}.pdf`

#### 场景:正常分页 — 截断点落在块间隙
- **当** 报告包含多个 `.pdf-block` 元素
- **那么** 每页 PDF 的截断点位于两个 `.pdf-block` 元素之间的空白区域
- **那么** 任何 `.pdf-block` 元素不会被同一截断点同时出现在两页上

#### 场景:降级分页 — 超长内容块
- **当** 单个 `.pdf-block` 元素高度超过 A4 页面高度
- **那么** 系统按 A4 高度在该块内部截断
- **那么** 截断后剩余部分继续按块间隙规则排版后续页面

#### 场景:容差回退 — 块间隙过小
- **当** 目标截断位置附近（±20px DOM 坐标）无可用块间隙
- **那么** 系统回退到固定 A4 高度截断
