# Decision Copilot — AI 决策辅助器

> 不是替你做决定，而是让每个决策的未来变得可推演、可比较、可解释。

---

## 痛点

在实际业务和产品决策中，我们经常面临复杂选择，但决策过程往往存在以下问题：

| 场景           | 典型困境                             |
| -------------- | ------------------------------------ |
| 是否上线新功能 | 无法准确评估收益与技术风险之间的权衡 |
| 资源如何分配   | 不确定投入在优化还是创新哪个更有效   |
| 是否进入新方向 | 缺乏对长期回报与不确定性的系统判断   |
| 产品策略选择   | 很难量化不同方案的综合影响           |

**核心问题：我们无法系统性地"推演不同决策路径的未来结果"。**

现有方式主要依赖经验判断、零散信息和简单分析工具，缺乏结构化与可解释的决策支持。

---

## 解决方案

Decision Copilot 通过大语言模型与量化分析引擎的结合，将复杂决策问题转化为**结构化建模 → 多路径推演 → 压力测试**的全流程，帮助用户从"经验驱动"转向"推演驱动"。

```
输入决策场景
    │
    ▼
AI 结构化建模 ───── 自动提取选项、变量、权重、因果链
    │
    ├── 决策树可视化：每个选项展开为多条未来路径
    ├── 实时交互：拖动滑块即时查看分数变化
    │
    ▼
量化仿真验证 ────── 蒙特卡洛 5000 次随机抽样
    │
    ├── 概率分布：P10/P50/P90 + 标准差，量化不确定性
    ├── 敏感性分析：±20% 扰动下排名是否依然成立？
    │
    ▼
对抗性审查 ─────── DEVIL Agent 攻击已有结论
    │
    ├── 偏置检测：乐观偏差 / 幸存者偏差 / 锚定效应
    ├── 冠军脆弱性分析：第一名方案最大的风险点
    │
    ▼
综合输出 ───────── 结构化结论 + 可解释归因 + 风险提示
```

## 使用层级

系统提供两种使用模式，适应不同的决策深度需求：

### 快速模式：建模 → 调参 → 看结果

适合日常决策，快速获取初步结论。

```
输入问题 ──▶ AI 建模（一次调用）──▶ 决策树 + 参数面板
                                        │
                            拖动滑块/选择偏好
                                        │
                            分数实时变化 + 归因
```

**操作路径：**

1. 在左侧面板输入决策问题，点击提交
2. 等待 AI 构建决策模型
3. 在参数面板调整滑块或选择风险偏好，观察分数变化
4. 点击决策树节点查看路径详情和溯源分析

### 深度模式：仿真 → 审查 → 流水线

适合重要决策，需要多维度验证。

```
快速模式完成
    │
    ▼
深度模拟 ──▶ 蒙特卡洛仿真（5000 次抽样）
    │           └── P10/P50/P90 分布 + σ 波动
    │
    ▼
敏感性分析 ──▶ 对每个变量 ±20% 扰动
    │            └── 排名稳定性：稳定 / 部分稳定 / 不稳定
    │            └── 哪些变量会导致排名翻转？
    │
    ▼
DEVIL 审查 ──▶ 对抗性攻击已有结论
    │            └── 发现被高估/低估的选项
    │            └── 检测认知偏置（乐观偏差/幸存者偏差等）
    │
    ▼
多 Agent 流水线（可选）──▶ 5 步独立推演
                FRAMEWORK → MODEL → SIMULATE → DEVIL → NEXUS
                └── 比单步建模更可靠，适合重大决策
```

**操作路径：**

1. 先完成快速模式建模
2. 点击"深度模拟"触发蒙特卡洛仿真
3. 在底部面板切换 Tab 查看敏感性分析和 DEVIL 审查
4. 点击左侧"多 Agent 流水线"按钮启动 5 步深度推演

## 核心特性

### 1. AI 决策建模

- 自动识别选项、变量与关键因素
- 构建结构化决策模型（选项 / 变量 / 权重 / 决策树 / 路径推演）
- 支持输入校验：拦截非决策类问题（闲聊、乱码等）

### 2. 多路径推演

- 每个选项对应多条逻辑路径（乐观 / 悲观 / 基准）
- 每条路径包含概率、时间线和影响因子
- 点击决策树节点查看从根到叶的完整路径链

### 3. 动态评估

- 参数调整后实时重算分数（~300ms 防抖）
- 分数差异归因：哪个维度拉动了分数变化
- 反事实场景：预设偏好按钮一键对比

### 4. 蒙特卡洛仿真

- 7 种概率分布（正态 / 对数正态 / Beta / 三角 / 均匀 / 伯努利 / 分类）
- 5000 次随机抽样，输出 P10 / P50 / P90 和标准差
- 自动根据用户偏好对齐概率分布

### 5. 敏感性分析

- 对每个变量 ±20% 扰动，记录排名变化
- 排名稳定性评级：稳定 / 部分稳定 / 不稳定
- 识别哪些变量的判断偏差会导致结论翻转

### 6. DEVIL 对抗性审查

- 攻击排名第一的选项，寻找被高估的理由
- 为排名最后的选项辩护，寻找被低估的价值
- 检测 7 种认知偏置（乐观偏差 / 幸存者偏差 / 锚定效应等）

### 7. 多 Agent 流水线

- 5 步独立 Agent：FRAMEWORK → MODEL → SIMULATE → DEVIL → NEXUS
- SSE 实时推送每步进度
- 支持断点续跑（从失败的步骤恢复）

### 8. 本地持久化

- 模型变更自动保存到 localStorage
- 刷新页面自动恢复上次决策状态
- 支持一键清除缓存

### 9. 结果解释与导出

- 不仅输出排名，同时说明原因、风险与适用场景
- 支持导出深度分析报告（PDF）

## 人机协作流程

```
┌──────────┐     ┌──────────┐     ┌──────────┐
│ 输入问题  │────▶│ AI 建模  │────▶│ 决策树   │
└──────────┘     └──────────┘     └────┬─────┘
                                       │
                              ┌────────▼────────┐
                              │ 快速：参数调节   │
                              │ 深度：仿真+审查   │
                              └────────┬────────┘
                                       │
                        ┌──────────────▼──────────────┐
                        │ 输出：结果 + 解释 + 审查     │
                        │       + 稳定性 + 建议        │
                        └─────────────────────────────┘
```

**人机分工：**

- AI：建模、推演、多路径分析、仿真、对抗审查
- 人：调整偏好、判断合理性、最终决策

## 为什么只有 AI 能做这件事

| 能力         | 传统工具         | Decision Copilot               |
| ------------ | ---------------- | ------------------------------ |
| 理解决策问题 | 依赖结构化输入   | 可直接理解自然语言描述         |
| 构建决策路径 | 规则预设         | 自动生成多路径推演             |
| 处理复杂权衡 | 难以建模         | 可量化收益、风险等多维因素     |
| 输出解释     | 仅结果数据       | 同时提供原因、风险与偏置检测   |
| 动态调整     | 静态分析         | 随用户偏好实时重算             |
| 压力测试     | 无               | 蒙特卡洛 + 对抗性审查          |

**系统本质不是"评分工具"，而是一个可以参与决策过程的 AI 协作系统。**

## 技术实现

| 层     | 技术                          |
| ------ | ----------------------------- |
| 前端   | Vue 3 + Vite + Element Plus   |
| 后端   | Node.js + Express 5           |
| LLM    | 通义千问（Qwen API）           |
| 通信   | REST API + SSE 流式推送       |
| 计算   | Decimal.js 高精度 + Monte Carlo |
| 存储   | localStorage 本地持久化        |
| 可视化 | 自定义决策树组件               |
