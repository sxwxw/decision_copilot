## 新增需求

### 需求:路径溯源视图

系统 SHALL 在用户点击决策树节点后，展示从根节点到该点击节点的完整路径链。路径链 SHALL 包含每个节点的名称、分值、概率和事件类型（正/负/中性）。

#### 场景:点击叶节点展示完整路径链
- **当** 用户点击 step=2 的叶节点
- **那么** 路径详情面板展示 root(step=0) → option(step=0) → outcome(step=1) → consequence(step=2) 四段节点链

#### 场景:点击中间节点展示部分路径链
- **当** 用户点击 step=1 的中间节点
- **那么** 路径详情面板仅展示从根到该 step=1 节点的路径

## 修改需求

### 需求:路径详情

原需求定义在 `openspec/specs/decision-core/spec.md` 中。

系统 SHALL 在用户点击决策树节点后展示路径详情。路径详情 SHALL 包含：
- 路径链视图：从根节点到点击节点的节点序列，每个节点展示名称、分值、事件类型
- 到达概率：从根到该节点的累积概率
- 时间线：匹配该路径的 timeline 数据（事件描述、影响值、阈值）
- 解释文本：LLM 生成的路径说明

**变更说明**：移除固定指标网格（metrics-col），将路径详情面板改为全宽布局。时间线占据全部宽度，路径链作为新增的可视化层展示在时间线上方。

#### 场景:点击节点触发路径溯源
- **当** 用户点击决策树中的任意节点
- **那么** 路径详情面板展示完整的路径链和对应时间线，不显示固定的 2x2 指标网格

#### 场景:未选中节点时显示占位
- **当** 用户尚未点击任何节点
- **那么** 路径详情区域显示空状态提示「点击决策树节点查看路径溯源」

### 需求:路径详情匹配逻辑

系统 SHALL 使用节点的 `id` 字段精准匹配路径，禁止使用字符串模糊匹配（如 `path.name.includes(nodeName)`）。

#### 场景:通过 id 精准定位路径
- **当** 用户点击某个节点
- **那么** 系统通过该节点的 `id` 在 treeData 中定位该节点及其祖先链

#### 场景:从 treeData 构建路径链
- **当** 节点被定位后
- **那么** 系统从该节点向上遍历 ancestors，收集所有祖先节点形成路径数组

## 移除需求

### 需求:路径详情包含量化指标网格

系统原需求要求路径详情展示收入/成长/风险/幸福指数的 2x2 指标网格。

**Reason**: 指标网格信息密度低、与点击节点无关联、挤占时间线展示空间。路径溯源视图通过展示完整路径链提供了更丰富的上下文信息。

**Migration**: 移除 metrics-col 相关模板和样式代码。四项指标（income/growth/risk/happiness）仍保留在 path 对象中，可通过解释文本或时间线中的 impact 标签间接获取。
