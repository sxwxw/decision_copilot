# spec: prob-normalizer

## 新增需求

### 需求:概率归一化

系统 SHALL 提供概率归一化工具，确保调整后的概率数组总和为精确 1.0。

#### 场景:归一化后概率和为 1.0
- **当** 一组概率值总和为 0.995 或 1.005（浮点误差范围内）
- **那么** normalizeProbabilities 返回的数组总和精确为 1.0，保留 2 位小数

#### 场景:处理非正数概率
- **当** 输入包含负数或 NaN 的概率值
- **那么** normalizeProbabilities 将其替换为 0 并重新归一化

#### 场景:全部为零时均匀分配
- **当** 所有概率值均为 0
- **那么** normalizeProbabilities 均匀分配为 1/N
