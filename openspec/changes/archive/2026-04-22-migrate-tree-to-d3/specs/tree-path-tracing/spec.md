# spec: tree-path-tracing

## 新增需求

### 需求:路径追溯高亮

系统必须在用户点击决策树任意节点时，追溯从根节点到该节点的完整路径，并对路径进行视觉高亮：
- 被点击节点到根节点路径上的所有节点卡片描边变为深紫色（#6366f1）
- 路径上的所有连线变为粗紫色
- 路径上的节点带有 CSS 呼吸灯动画效果
- 非路径上的所有节点和连线 opacity 降至 0.2
- 追溯完成后触发 nodeClick 事件，通知父组件

#### 场景:点击叶子节点
- **当** 用户点击决策树叶子节点
- **那么** 从根到该叶子的整条路径高亮为紫色，其他路径淡化

#### 场景:点击中间节点
- **当** 用户点击非叶子的中间节点
- **那么** 从根到该节点的路径高亮，子节点路径保持正常状态

#### 场景:取消高亮
- **当** 用户再次点击已高亮节点或点击空白区域
- **那么** 所有节点和连线恢复正常透明度和样式
