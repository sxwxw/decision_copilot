## 上下文

AI-Decision-Engine 的 simulator 自动做 ±20% 扰动，记录每次扰动后的排名变化，计算 stability 和 gap_pct。

## 目标 / 非目标

**目标：**
- 自动对每个变量做 ±20% 扰动
- 计算排名稳定性（stable/partially_stable/unstable）
- 计算第1 vs 第2 的效用差距
- 在 UI 中展示敏感性分析结果

**非目标：**
- 不引入可视化图表（蜘蛛图等），先做文字展示
- 不替代用户手动拖滑块的功能

## 决策

### 1. 计算方式

对每个变量 v：
- v += 20% → recalcScores() → 记录排名
- v -= 20% → recalcScores() → 记录排名
- 统计排名变化次数

稳定性判定：
- 0 次翻转 → stable
- ≤ 总扰动数/4 次翻转 → partially_stable
- 否则 → unstable

### 2. 展示方式

底部面板"敏感性分析"tab，文字展示：
- 排名稳定性指标
- 第1 vs 第2 差距
- 最容易翻转排名的变量列表

## 风险 / 权衡

[风险] → 敏感性计算在主线程执行，变量多时可能卡顿
→ 缓解：变量数 ≤ 10 时直接计算；后续可迁移到 Web Worker
