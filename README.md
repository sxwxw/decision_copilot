# Decision Copilot — AI 决策辅助器

> 不是替你做决定，而是让每个决策的未来变得可推演、可比较、可解释。

---

## 痛点

复杂业务和产品决策中，我们缺乏系统性地"推演不同决策路径未来结果"的能力。现有方式依赖经验判断和零散信息，缺少结构化、可解释的决策支持。

---

## 解决方案

Decision Copilot 将大语言模型与量化分析结合，提供 **结构化建模 → 多路径推演 → 压力测试** 的完整流程：

```
输入决策场景
    │
    ▼
AI 结构化建模 ───── 自动提取选项、变量、权重、因果链
    │
    ▼
量化仿真验证 ────── 蒙特卡洛 5000 次随机抽样
    │
    ▼
对抗性审查 ─────── DEVIL Agent 攻击已有结论
    │
    ▼
综合输出 ───────── 结构化结论 + 可解释归因 + 风险提示
```

---

## 使用方式

### 快速模式：建模 → 调参 → 看结果

输入决策问题 → AI 自动构建模型 → 决策树 + 参数面板 → 拖动滑块实时观察分数变化。

### 深度模式：仿真 → 审查 → 流水线

在快速模式基础上，触发蒙特卡洛仿真、敏感性分析和 DEVIL 对抗审查，或通过多 Agent 流水线（FRAMEWORK → MODEL → SIMULATE → NEXUS）进行独立推演。系统支持内循环自我校准模型偏差、外循环重塑决策框架。

---

## 核心特性

| 特性 | 说明 |
| - | - |
| AI 决策建模 | 自动识别选项、变量与关键因素，构建结构化决策模型；支持输入校验拦截非决策类问题 |
| 多路径推演 | 每个选项展开为多条逻辑路径（乐观/悲观/基准），点击节点查看完整路径链 |
| 动态评估 | 参数调整实时重算分数（~300ms 防抖），支持分数差异归因和反事实场景对比 |
| 蒙特卡洛仿真 | 7 种概率分布，5000 次抽样，输出 P10/P50/P90 和标准差 |
| 敏感性分析 | 对每个变量 ±20% 扰动，评级排名稳定性（稳定/部分稳定/不稳定） |
| DEVIL 对抗审查 | 多阶段攻击（框架偏见→模型失真→仿真假设→综合结论），检测认知偏置 |
| 多 Agent 流水线 | 4 步独立推演 + 内/外循环自我校准，SSE 实时推送进度，支持断点续跑 |
| 模型修正 | 根据用户偏好触发模型重新建模，迭代优化 |
| 本地持久化 | 自动保存至 localStorage，刷新恢复，支持一键清除 |
| 结果导出 | 支持导出深度分析报告（PDF） |

## 技术栈

| 层 | 技术 |
|------|------|
| 前端 | Vue 3 + Vite + Element Plus |
| 后端 | Node.js + Express 5 |
| LLM | 通义千问（Qwen API） |
| 通信 | REST API + SSE 流式推送 |
| 计算 | Decimal.js 高精度 + Monte Carlo |
| 可视化 | 自定义决策树 + ECharts |

## 快速开始

```bash
npm install
npm run server:dev
npm run dev
```

访问 `http://localhost:5173` 开始使用。

## 适用场景

所有"多选项 + 多变量 + 不确定性高"的决策问题：产品策略、资源分配、项目评估、战略规划、个人决策等。
