# 变更：初始化决策辅助器核心功能

## 背景

项目已通过 Vite + Vue 3 初始化骨架，目前仅有默认的 HelloWorld 模板。需要在此基础上构建完整的 AI 决策辅助器前端 UI + Express 后端 + Qwen LLM 集成。

## 目标

- 实现 `/decision` 页面三栏布局（输入区 → 参数面板 → 结果区）
- 元数据驱动参数面板（根据 LLM 返回结构动态渲染控件）
- ECharts 决策树可视化，支持点击节点联动路径详情 + 路径高亮
- Express 后端代理 Qwen API，提供决策建模和深度推演接口
- 分阶段联调：先用 Mock 数据跑通前端，再接入真实 LLM

## 非目标

- 用户认证、注册、登录
- 决策历史持久化存储
- 移动端适配（本期仅桌面端）
- 多语言国际化
