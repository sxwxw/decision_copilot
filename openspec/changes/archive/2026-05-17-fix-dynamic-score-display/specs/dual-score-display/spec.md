# Spec: dual-score-display

## 修改需求

### 需求:双分显示

系统 SHALL 在所有分数展示区域（含方案概览、ForkComparison 分叉卡片、PathDetail 路径溯源卡片）采用"计算分为主分 + LLM 基准分为副分"的双分显示策略。

#### 场景:ForkComparison 分叉卡片展示动态分值
- **当** 用户处于分叉对比模式
- **那么** 每个子分支的"分值"展示使用 `getAdjustedScore(branchName)` 计算出的调参后分数
- **并且** 当无调参时（参数均为默认值 50）动态分数等于基准分

#### 场景:PathDetail chain-card 展示动态分值
- **当** 用户处于路径溯源模式
- **那么** 路径链中每个步骤卡片展示的分值使用 `getAdjustedScore(optionName)` 计算出的调参后分数
- **并且** 步骤卡片 SHALL 同时显示 LLM 基准分以便对比

#### 场景:推荐结论卡片展示双分
- **当** 用户进入决策页面且已有建模结果
- **那么** 推荐结论卡片中每个方案的主分展示前端计算后的 adjusted score（大号字体）
- **并且** 每个方案的副分展示 LLM 原始 scores 值（小号灰色字体，标注为"基准"）
- **并且** 当计算分与基准分差值绝对值 > 5 时，显示差异指示标签

#### 场景:差异指示样式
- **当** 计算分 > 基准分 + 5
- **那么** 显示绿色向上箭头，提示"更匹配您的偏好"
- **当** 计算分 < 基准分 - 5
- **那么** 显示黄色向下箭头，提示"与您的偏好存在冲突"

#### 场景:方案概览卡片展示双分
- **当** 用户点击根节点进入方案概览视图
- **那么** 概览卡片中的分数使用前端计算后的 adjusted score 作为主分
- **并且** 卡片 SHALL 显示该方案与基准分的差值
